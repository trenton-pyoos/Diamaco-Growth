# Diamaco Growth

> South Africa's premier business growth partner. We systematise, scale, and sustain the businesses of tomorrow — today.

Diamaco Growth is a modern web application and corporate showcase designed for high-growth South African businesses. The platform highlights key solutions including workflow automation, CRM setup, lead generation, website development, tender readiness, and WhatsApp business automation.

---

## 🚀 Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Routing**: [React Router v7](https://reactrouter.com/)
- **Styling**: Modern CSS modules, responsive design, dark-mode inspired glassmorphism and accents
- **Interactivity**: Smooth scrolling, custom interactive cursors, floating WhatsApp assistance, and scroll reveal animations

## 🛠️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+ recommended)
- `npm` or `yarn` / `pnpm`

### Installation & Local Development

1. Navigate to the React application directory:
   ```bash
   cd diamaco-react
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the Vite development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:5173
   ```

### Building for Production

To create an optimized production bundle:

```bash
cd diamaco-react
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
